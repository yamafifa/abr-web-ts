# サーバーの起動と停止

## 起動

先に Docker を起動しておきます。

### 1. DB を起動する（abr-batch のフォルダで）

```bash
cd ~/work/abr-batch
npm run db:up
```

すでに DB が動いていれば、この手順は不要です。Elasticsearch と Kibana も一緒に起動します。

Elasticsearch 検索（`/es`）を使うときは、インデックスを作っておきます（約 1 分）。DB の中身を変えたあとは、もう一度実行すると Elasticsearch に反映されます。

```bash
npm run es:index
```

### 2. アプリを起動する（abr-web-ts のフォルダで）

```bash
cd ~/work/abr-web-ts
```

起動の仕方は 2 通りあります。

**開発モード（ふだんはこちら）**：コードを保存すると、すぐ画面に反映されます。

```bash
npm run dev
```

**本番モード**：ビルド（公開用に変換すること）してから動かします。画面の表示は速いですが、コードを変えたら、もう一度ビルドが必要です。

```bash
npm run build && npm run start
```

どちらも、ブラウザで http://127.0.0.1:3000 を開きます。

## 停止

**自分のターミナルで起動した場合**：そのターミナルで **Ctrl + C** を押します。

**バックグラウンドで動いているものや、どこで動いているか分からない場合**：

```bash
pkill -f next-server
```

止まったかどうかは、次のコマンドで確かめます。何も表示されなければ止まっています。

```bash
ss -ltn | grep :3000
```

**DB も止めたい場合**（abr-batch のフォルダで）：

```bash
npm run db:down
```

DB を止めてもデータは消えません。次に `npm run db:up` で起動すれば、そのまま使えます。

## 注意

- 前に起動したサーバーが動いたままだと、3000 番ポートが使われているので、`npm run dev` は 3001 番など別のポートで起動します。先に止めてから起動してください
- DB が止まっていると、画面を開いたときに接続エラーになります
